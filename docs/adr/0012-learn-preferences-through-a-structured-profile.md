# Learn Theo preferences through a structured profile

Theo automatically extracts stable user preferences from explicit or repeated conversational evidence into a visible, versioned Theo Profile layered as User Profile, Project Profile, and Session Overrides. Narrower scope takes precedence, Theo asks when storage scope is unclear, and every update produces a quiet notice with undo, editing, and clearing. Secrets, one-off project facts, quoted instructions, and uncertain inferences are excluded; explicit instructions outrank inference, session instructions remain temporary unless remembered, newer repeated evidence may replace older inference, and unresolved conflicts require a question. Each session's Theo Activation Prompt is generated from the fixed role and safety boundaries plus that structured profile rather than being rewritten directly. This supports continuous personalization without turning arbitrary conversation content into permanent instructions.
